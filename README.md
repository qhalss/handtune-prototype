# HandTune Prototype

웹캠 기반 손 인식으로 어린이 소근육 발달 활동과 시니어 손 기능 재활성화 활동을 제공하는 로컬 실행용 프로토타입입니다.

## 실행 방법

압축을 푼 폴더에서 터미널을 열고 실행합니다.

```bash
python -m http.server 8000
```

Mac에서 `python` 명령이 안 되면 다음을 사용하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

카메라 권한을 허용해야 합니다. 카메라 기능은 localhost 또는 HTTPS 환경에서 동작합니다.

## 주요 흐름

1. 어린이 / 시니어 모드 선택
2. 카메라 기반 손 상태 측정
3. 측정 결과와 추천 게임 2개 확인
4. 추천 게임 2개와 나머지 게임 3개 선택
5. 게임 진행
6. 점수판 및 오늘 활동 기록 확인

## 이번 버전의 핵심 수정

- 보석 끼우기: 보석을 집어서 구멍에 옮긴 뒤 손가락을 펼쳐 놓아야 성공합니다.
- 과일 바구니 분류: 과일과 바구니 위치를 화면 안에서 명확하게 재배치했습니다.
- 무지개 그리기: 손바닥 중심점으로 큰 무지개 곡선을 순서대로 따라갑니다.
- 물컵 배달하기: 손바닥 중심점으로 꺾인 배달길을 천천히 이동합니다. 너무 빠르거나 길 밖으로 나가면 흔들림이 증가합니다.
- 색깔 손놀이: 빨강, 노랑, 초록, 파랑, 보라 5가지 지시에 맞춰 손 펴기, 집기, 주먹, 검지만 펴기, 브이 손가락을 수행합니다.
- 잡기 동작은 손가락을 오므린 채 이동하는 방식으로는 성공하지 않도록, 펼침 → 집기 → 다시 펼침 흐름을 사용합니다.
