# HandTune Prototype

웹캠으로 손 움직임을 인식해 현재 손 상태를 측정하고, 부족한 항목 2개에 맞는 추천 게임과 난이도를 제공하는 로컬 실행용 프로토타입입니다.

## 포함 흐름

1. 어린이 / 노인 모드 선택
2. 카메라 기반 현재 상태 측정
   - 빛나는 점을 엄지와 검지로 잡기
   - 속도, 정확도, 가동범위, 안정성, 협응 측정
3. 측정 결과 화면
   - 가장 낮은 항목 2개 표시
   - 항목별 추천 게임 1개씩, 총 2개 추천
   - 난이도는 쉬움 / 보통 / 어려움으로 통일
4. 게임 선택 화면
   - 첫 번째 행: 오늘 추천 게임 2개
   - 두 번째 행: 나머지 게임 3개
5. 카메라 기반 게임 진행
6. 게임 종료 점수판
7. 오늘 활동 기록 페이지

## 실행 방법

압축을 푼 폴더에서 터미널을 열고 실행하세요.

Windows:

```bash
python -m http.server 8000
```

Mac:

```bash
python3 -m http.server 8000
```

브라우저에서 접속:

```text
http://localhost:8000
```

카메라 권한을 허용해야 합니다.

## 주의

카메라 기능은 보안 정책 때문에 `localhost` 또는 HTTPS 환경에서만 정상 작동합니다. 기존 버전을 열었던 브라우저에서는 캐시가 남을 수 있으므로 `Ctrl + Shift + R`로 강력 새로고침하세요.
